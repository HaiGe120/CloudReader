# CloudReader 1.2.3 for Windows and Linux

[Download the desktop preview](https://github.com/HaiGe120/CloudReader/releases/tag/v1.2.3-desktop-preview)

CloudReader 1.2.3 brings shelf artwork and the latest reader and assistant changes to Windows 10/11 x64 and Debian 12 amd64.

- See embedded EPUB, FB2 and CBZ covers and PDF first-page thumbnails in existing and newly imported libraries.
- Choose System, Light or Dark appearance. Click the compact progress indicator to reopen reading controls.
- Resume a book’s latest conversation or start another. Preview the passage and nearby text, choose whether to include them, and send with Ctrl+Enter.
- Browse provider models, enable web search on supported providers, or select a word to translate with your configured provider. Saved keys are bound to their provider origin.

Download the MSI for Windows or the DEB for Debian. Both include the Java runtime. The Windows MSI is unsigned. Installed upgrades with existing libraries and live provider accounts still need testing.

All 56 desktop tests passed on each target OS. The packaged launchers opened the library, turned a WebKit page, rendered a PDF, displayed both Settings palettes and verified the bundled Google client.
