# K07.txt_pdf — Android TXT/PDF host progress behavior

Status: **TXT/PDF host behavior is integrated through the K07.session controller; parent K07 remains active only for device lifecycle verification and EPUB work stays in K08.**

## Scope delivered

- TXT restores valid `txt:<UTF-16 offset>:utf16` positions and falls back to normalized progress for malformed/out-of-range offsets. Debounced checkpoints are flushed on host stop, close, and disposal.
- PDF records the latest visible page and flushes it on stop. Writes use the repository's progress-only update so favorite state is preserved; PDF zoom remains owned by the native viewer.
- No EPUB, database schema, or sync behavior changed. Checkpoint scheduling and progress-only writes now live behind the shared session controller; see [K07.session evidence](K07.session.md).
