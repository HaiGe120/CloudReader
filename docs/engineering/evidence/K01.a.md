# K01.a Android domain, storage, and wire boundary evidence

Date: 2026-10-20. K01.a is **done** after review; K01.b fixture adoption is separate.

## Change and acceptance

- Added Room-free Android domain values and moved `BookFormat`, chat records/messages, tombstones, demo-book constants, and timestamp/UUID helpers out of the Room model file.
- Room entities now have explicit entity↔domain mappings. The database keeps the `cloudreader.db` name, Room version 1, and the existing table/column definitions and identity hash from K04.
- Sync/wire decoding produces domain values. Persisted conversation JSON and sync conversation payloads use one Android-/Room-free `ConversationJsonAdapter`; repository and sync merge code operate on domain snapshots, not Room rows.
- Restored `LibraryDao.snapshot()` as a transactional entity snapshot. The repository maps it to `LibrarySnapshot` after the transaction returns.
- Focused mapping tests retain device-only paths and opaque book/tombstone/conversation/message data; a populated-database instrumentation assertion covers fractional timestamps and conversation extras.

The schema remains unchanged and no data migration was performed. C01 fixture adoption, stricter wire safety checks, and unknown-format compatibility remain K01.b. C02's new merge policy is not implemented here.
