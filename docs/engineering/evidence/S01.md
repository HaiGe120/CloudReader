# S01 Apple unknown schema-v1 data preservation evidence

Date: 2026-10-20. Apple S01 implementation and verification are complete; Android shared-fixture instrumentation is owned by K05.

## Change and acceptance

- Apple manifest and local persistence models retain unknown JSON values at the root, synced-book entry, book, book tombstone, conversation, and message levels. The opaque sidecar keeps JSON dictionaries out of domain-facing views and preserves values through decode, local save/reload, known-field edits, record replacement, and re-encode.
- Unknown conversation roles remain explicit `.unknown(rawValue)` values and encode back to the same string.
- Schema v1 remains the only accepted and encodable version. Decoding an unsupported version fails before the sync coordinator can publish its contents; encoding a manually constructed unsupported version also fails.
- The existing shared `Contracts/v1/fixtures/nested-unknown.json` is loaded directly by package and iOS persistence tests. Its `futureRoot.futureNull` member exercises JSON null, and the expected disposition now describes null, booleans, numbers, arrays, and objects. No fixture payload was copied into tests.
- No XcodeGen specs, generated project files, or package locks were changed for S01. Android source and tests were left untouched.
