# A04.b.navigation — Shared EPUB link classification

Status: **complete with a refined boundary**.

`Apps/Shared/EPUBNavigationPolicy.swift` classifies spine chapters and non-spine HTML/XHTML/SVG documents and carries URL fragments through the decision. The iOS WebKit host still performs containment/existence checks and presents note sheets. macOS intercepts spine navigation and retains its existing internal-resource loading behavior. Both apps keep their native host and bridge code.

The bridge JavaScript and CSS remain platform-specific after source comparison showed meaningful behavior differences: iOS and macOS have different viewport restoration, SVG styling, layout controls, fragment-progress behavior, and progress debounce intervals. Sharing those files would overwrite existing native behavior without a stable common contract.
