# K06.assistant — Android assistant state and request lifecycle

Status: **complete at local code and automated-test gates**. Device recreation and live AI-provider behavior remain unverified.

## Scope delivered

- Added lifecycle-aware `AssistantViewModel` and immutable `AssistantUiState` for selected conversation, draft, consent, busy, and error state. `SavedStateHandle` restores the active conversation ID; busy state always starts false.
- Persisted the user question before sending and the assistant answer after success. Cancel leaves the question available for retry. Retry reuses the latest question and honors the current context consent.
- New conversations default to context off. A saved conversation's consent restores with the chat. Opting out persists immediately and removes the previously saved selected passage/book excerpt from that chat.
- Replaced blocking Android `Call.execute()` with a cancellable OkHttp enqueue bridge. Coroutine cancellation calls `Call.cancel()`; a response that arrives after cancellation is closed. Endpoints, payloads, and the three protocol decoders remain unchanged.
