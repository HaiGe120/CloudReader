- `AIConversationMessage`, `AIConversationRecord`, `AIConversationDeletion`, `SyncedBook`, and `RemoteLibraryManifest` now have one definition in Foundation-only `CloudReaderCore`.

- iOS and macOS import the same shared model declarations. Codable keys, optional-field omission, manifest/profile defaults, raw enum values, and fractional Foundation-reference dates are covered by package tests. Provider transport and sync coordination remain app services.
- No project specs, generated-project files, or lock files changed for this slice. Unknown remote fields remain S01; provider extraction remains A07.
