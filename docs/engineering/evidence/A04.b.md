# A04.b — Shared EPUB resource policy

Status: **resource-policy child complete**. Navigation/footnote bridge sharing remains a separate pending child of A04.b.

## Scope delivered

- Added `Apps/Shared/EPUBResourcePolicy.swift` and connected both native WebKit resource handlers to the shared policy. WKURLSchemeTask scheduling, cancellation, and platform MIME discovery remain in iOS/macOS adapters.
- Canonicalized the extraction root and resource URL through symlinks before containment checks. Absolute paths, backslashes, NULs, traversal outside the root, and symlinks escaping the root are rejected; parent-relative links that remain inside the EPUB root are allowed.
- Normalized MIME types and charset parameters, recognized HTML/XHTML, preserved UTF-8/UTF-16 decoding, and inserted the existing restrictive CSP immediately after `<head>` or at the document start when no head exists.
- Added tests for contained parent-relative paths, path traversal, inside/outside symlinks, MIME normalization, and CSP placement in `EPUBPublicationTests.swift`.

## Verification

- Regenerated the canonical iOS and macOS projects from their XcodeGen specs; both include the new `Apps/Shared` source.
- Full iOS simulator suite — passed **88/88, 0 failures** at `<local path>`.
- Full macOS suite — passed **2/2, 0 failures** at `<local path>`; this verifies integration/build but the Mac target has no focused resource-policy assertions.
- CloudReaderCore package suite — passed **26/26, 0 failures** at `<local path>`.
- The first iOS run exposed a test expectation error about CSP placement (the policy is inserted directly after the opening `<head>` tag). Corrected the assertion and reran the full iOS suite successfully; no production behavior change was needed.
- `git diff --check`, Swift parsing, shared-helper typechecking, and the worker's standalone containment/MIME/CSP harness passed.

## Limits

The path is canonicalized before the file is read, so a hostile local process could theoretically replace a symlink in the interval between validation and reading. No live OS picker/provider or interactive cross-platform EPUB round trip was performed. JS/CSS navigation and footnote policy remain pending under `A04.b.navigation`.
