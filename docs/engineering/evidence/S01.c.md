# S01.c — Apple shared-fixture sync preflight

Status: done.

Apple now consumes the same 13 C01 input/expected fixture pairs as Android. Package tests classify accepted, characterization-only, compatibility-gap, preservation, and rejection cases separately. Existing opaque-field round-trip tests remain responsible for proving unknown JSON values survive at all supported record boundaries; unknown conversation roles remain opaque `.unknown(String)` values.

`RemoteLibraryManifest.validateForRemoteSync()` validates remote metadata after decoding and before sync applies tombstones, reads book objects, installs local files, or publishes a new manifest. It rejects unsupported versions, malformed lower-case SHA-256 digests, unsafe filenames, out-of-range progress, and non-finite timestamps. Codable decoding for local persistence remains unchanged for legacy compatibility. Typed unknown book formats are rejected during decode. `unknown-role` remains accepted as characterization; `deletion-equal-time` remains parse-only because merge policy is outside this card.
