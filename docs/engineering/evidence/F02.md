## iOS test isolation

`BookLibraryTests` now creates a UUID-scoped temporary storage root and a unique `UserDefaults` suite per test. Tests that reload the same library reuse that test's root and defaults. `CloudSyncCoordinator` accepts an injected defaults instance while retaining `.standard` in production; the provider-selection test uses the isolated suite. Other iOS test sources were inspected: library and inbox tests use temporary roots, and EPUB cache cleanup is scoped to UUID book IDs.

Both Apple app hosts now recognize the test scheme's `CLOUDREADER_TEST_HOST=1` setting, use a unique temporary library/preferences suite, and avoid presenting normal app UI during tests. The iOS host skips shortcut registration; neither test host seeds the demo book or schedules provider sync. The generated iOS and macOS test schemes set this variable. Production initialization still uses the existing app library and standard preferences.
