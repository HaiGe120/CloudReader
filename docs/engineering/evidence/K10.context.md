# K10.context — Bounded Android local context reads

Status: **bounded file reader and local automated gates complete**.

`ai/BoundedContextReader.kt` reads TXT and generated PDF-context files through a small buffer and retains at most the existing 18,000 UTF-16-code-unit prompt limit. It recognizes UTF-8, UTF-16LE, and UTF-16BE when their matching BOM is present; unmarked input defaults to UTF-8. It avoids returning half of a surrogate pair when the cap falls between its code units. `AssistantSettingsScreen` no longer reads the full local file before applying the cap. AI request payloads and saved-chat schema are unchanged.
