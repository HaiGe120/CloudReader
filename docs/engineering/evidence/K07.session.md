# K07.session — Android TXT/PDF reader checkpoint controller

Status: **controller and local automated gates complete; device lifecycle verification remains open**.

`ReaderSession` owns each book's pending progress/location checkpoint and debounce/flush boundary. The TXT Compose host records validated UTF-16 offsets; the PDF fragment records the latest visible page. Both writers resolve the current row by stable book ID and call the repository's progress-only mutation, preserving favorites and unrelated row state. Session state is synchronized across UI callbacks and application-scope delay/write coroutines, and writes are serialized so a checkpoint arriving during an in-flight write is not lost or persisted out of order.
