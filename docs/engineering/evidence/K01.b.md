# K01.b Android shared-fixture and adapter evidence

Date: 2026-10-20. K01.b is **done** after integrator review.

## Change and acceptance

- Android instrumentation reads all 13 input fixtures and their sibling expected files directly from `Contracts/v1/fixtures`; the test contains no duplicate contract payloads.
- Assertions cover accept/reject classifications, legacy defaults, fractional timestamps, UUID normalization, object names, unknown conversation roles, and nested unknown-value round trips. A malformed-ID case checks fail-closed behavior.
- A temporary Room database verifies that book, book tombstone, conversation, and message unknown values survive reload and a known-field edit. The test checks the values again in their wire encoding.
- The Android wire codec now rejects malformed UUIDs, non-lowercase or malformed SHA-256 values, non-finite numeric fields, and progress outside the inclusive `[0,1]` range. Unknown optional book formats remain rejected safely.

The deletion-equal-time fixture was parse-only in this K01.b slice and did not specify production merge behavior; C02 and the later paired S03/K02 milestone define and implement that policy. Android preserves root and synced-book-entry unknown values in the decoded manifest representation, while local durable preservation is verified for book, tombstone, conversation, and message records. At K01.b completion, C02's deterministic merge policy and cross-provider convergence remained unimplemented; see [K02 evidence](K02.md) for the later adoption.
