# K04 Android database upgrade safety evidence

Date: 2026-10-20. K04 is **done**.

## Change and acceptance

- `CloudReaderDatabase` now exports its current Room schema, checked in at `Apps/Android/app/schemas/io.github.haige120.cloudreader.data.CloudReaderDatabase/1.json`.
- The database name remains `cloudreader.db`; entity/table/column definitions and version 1 remain unchanged.
- Removed the destructive-migration fallback. An unsupported upgrade now fails open rather than deleting the user's library.
- Isolated instrumentation tests verify that a populated v1 database opens with book metadata, local location, conversation data, and both tombstone sets intact; a database marked as a future version fails to open while its existing row and version remain intact.
