# D02 Kotlin core extraction evidence

Date: 2026-10-24

Implemented the first Android-independent Kotlin/JVM contract module at
`Packages/CloudReaderKotlin` and wired it into the desktop composite build and
Android `:app` dependency graph.

## Covered code

- v1 portable models and Foundation-reference-date helpers
- conversation JSON adapter with unknown-field preservation
- v1 manifest/book/tombstone codec and filename/hash/progress validation
- deterministic merge policy, JCS-style canonical comparison, tombstone rules,
  and opaque recovery candidates
- assistant profile, bounded context instructions, request payload builders,
  response decoding, and transport/credential/remote-store ports
- root facade aliases for desktop callers that do not need package-layer details

## Checks

- Added contract, merge, assistant, and desktop shared-core smoke tests.
- Android sync performs shared-core manifest preflight before applying the
  existing Android storage merge.
- Core tests now pass locally with the installed Homebrew JDK 17 using the
  cached dependencies (`./Packages/CloudReaderKotlin/gradlew -p
  Packages/CloudReaderKotlin test --offline`). Desktop tests could not run
  locally because the Compose Desktop Gradle plugin is not cached; GitHub
  Actions remains the authoritative desktop build check.
- The Android check resolved and compiled the shared `CloudReaderKotlin` jar
  before failing in the existing `:app:mergeDebugResources` task while hashing
  a generated resource file whose name contains a space. No Android source or
  resource repair was made for that unrelated baseline failure.

## Remaining limits

- Android production models and merge implementation remain in place while the
  shared module is adopted incrementally; a later bounded migration must remove
  duplicate behavior after the shared fixture gate passes.
- Desktop PDF/EPUB engines, native credential adapters, drag/drop, accessibility,
  provider sync, and Windows/Linux packaging remain unverified.
