## Changes

- `MainActivity.onStart` calls `requestSync(FOREGROUND)`.
- The existing debounced library/conversation watcher calls `requestSync(LOCAL_CHANGE)`.
- The library header exposes “Sync now” and calls `requestSync(MANUAL)`.
- `CloudReaderApp` observes provider selection at application scope, skips the initial DataStore snapshot, and launches each actual selection-change request independently so updates can reach the coordinator during an active sync. This observer survives Activity recreation.
- `CloudReaderApp.requestSync` waits for app initialization, routes through `SyncEngine.request`, and updates the shared `syncOutcome` used by existing status and failure feedback.
- No production trigger in the four owned screens/application files calls deprecated `sync()`.
