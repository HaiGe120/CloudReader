# A03 — Shared Apple import orchestration

Status: implementation complete at code and automated-test gates. Interactive picker/drop smoke with real OS document providers remains open.

`Apps/Shared/BookImportCoordinator.swift` serializes OS-resolved URLs, keeps security-scoped access through the import, preserves order/per-file outcomes, acknowledges iOS inbox files only after the durable library commit, and opens the first successful import. `BookLibrary.importBooksAsync` stages copies and metadata away from the main actor, then commits the library index and rolls back copied files if persistence fails. iOS and macOS retain their native entry points; the Mac picker/drop routes now share the coordinator. Both XcodeGen specs exclude the preserved older `AppleSyncPipeline 2.swift` and `BookImportCoordinator 2.swift` copies from compiled sources without deleting or editing them.
