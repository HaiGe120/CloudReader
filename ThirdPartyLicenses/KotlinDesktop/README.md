# Kotlin and desktop license copies

These are verbatim upstream license/attribution texts for dependencies described
in the root `THIRD_PARTY_NOTICES.md`. `upstream-provenance.json` records the
retrieved upstream repository/ref/path. Dependencies keep their own terms;
CloudReader's MIT license does not replace them.

OpenJFX's full native-module legal notices, notices retained in the actual APK
and desktop JARs, Android runtime Maven license metadata and Java runtime legal
files accompany the binary release in its third-party-notices ZIP. Full matching
Temurin and OpenJFX source archives are separate assets in the same release.
The generic Skia BSD text does not identify an exact native binary source commit.
